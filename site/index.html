本地跑起来

  1. 装依赖：Python 3.8+ 与 ffmpeg（需在 PATH 中）。numpy / opencv / jieba 为可选依赖，缺了仅相关脚本不可用。
  2. 体检：python scripts/doctor.py --video your.mp4，一次性汇总构图 + 音频。
  3. 按需单项：detect_faces.py / split_sentences.py / check_card_layout.py / check_pip.py 等，每个都支持 --help。
